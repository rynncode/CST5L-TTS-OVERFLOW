Overflow is a dark-themed personal task management web application built with PHP and MySQL. It lets users register and log in to a private workspace where they can create, organize, and track tasks by priority and status. The dashboard gives an at-a-glance view of all tasks through four stat counters (Total, Pending, In Progress, Completed), a due date urgency widget that surfaces overdue and upcoming tasks with visual indicators, and a filterable, searchable task table. Tasks can be toggled complete directly from the dashboard without leaving the page. Each task supports a title, description, priority level (Low, Medium, High), status (Pending, In Progress, Completed), and an optional due date with overdue and due-soon highlighting. Tasks can be created, viewed in detail, edited, and deleted, with status also changeable from the detail view. The UI features two animated canvas transitions: a star-field convergence on login and a black hole sequence on logout, alongside a geometric SVG background on the auth pages. The sidebar provides quick filtering by status and priority, and the entire interface is built around a custom dark design system with CSS variables, a consistent icon set drawn in inline SVG, and a Space Grotesk + Bebas Neue type pairing. Stack: PHP 8, MySQL (MySQLi), vanilla JS, custom CSS. No frameworks, no dependencies.
